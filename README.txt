HistoMap — бастапқы жұмыс істейтін прототип

ІСКЕ ҚОСУ:
1) ZIP архивті ашыңыз.
2) index.html файлын браузерде ашыңыз. Негізгі бөлімдер мен тесттер жұмыс істейді.
3) PWA ретінде орнату және офлайн кэшті пайдалану үшін папканы HTTPS қолдайтын хостингке жариялау керек (мысалы, GitHub Pages немесе Netlify).
4) iPhone: сайтты Safari-де ашыңыз → Share → Add to Home Screen.

ҚҰРЫЛЫМЫ:
- index.html — интерфейс, үш тілдегі мәтіндер, бөлімдер және тест логикасы.
- assets/krmu-logo.jpeg — пайдаланушы жіберген КРМУ логотипі.
- manifest.webmanifest — PWA параметрлері.
- sw.js — офлайн кэшке арналған Service Worker.

ЕСКЕРТУ:
Бұл оқу прототипі. Атлас ішіндегі суреттер әзірге демонстрациялық белгішелер; нақты микрофотосуреттерді тек пайдалануға рұқсаты бар немесе ашық лицензиялы материалдармен алмастыру керек. Оқу мазмұнын кафедра оқытушысы тексеруі қажет. Бұл құрал диагноз қоюға арналмаған.
